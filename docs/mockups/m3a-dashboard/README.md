# M3a dashboard mockup (offline, sample data)

A static mockup of the M3a observer page (0010 §7), for review before any view is wired to
the live API. It is not package data, `ApiServer` does not serve it, and it connects to
nothing. The data is a real capture replayed statically (`sample/README.md`), plus
hand-made rows that the page tags **synthetic**.

## Open it

With no server, from the worktree root:

```sh
xdg-open docs/mockups/m3a-dashboard/index.html
# or
google-chrome "file://$PWD/docs/mockups/m3a-dashboard/index.html"
```

With a local static server (loopback only), from the worktree root:

```sh
python3 -m http.server 8799 --bind 127.0.0.1 --directory docs/mockups/m3a-dashboard
# then open http://127.0.0.1:8799/
```

View presets in the URL hash, view-only: `#ecu=engine`, `#service=19`,
`#outcome=no_response,unrouted,error`, `#paused`, `#cleared`, `#tail` (scroll the log to
the newest row). Combine them with `&`, for example `index.html#outcome=error&paused`.

## Files

- `index.html`, `dashboard.css`, `dashboard.js`: the page; classic scripts, no modules,
  so it runs from `file://`.
- `sample-data.js`: generated by `python3 build_sample_data.py` from `sample/*.json`.
- `sample/`: the raw capture and how it was made.
- `screenshots/`: PNGs, and `take-screenshots.sh <absolute path of this directory>` to
  redo them with headless Chrome.
